# Ek Aur Aayega! – Overload Auto

A free, funny one-tap game by **HEYYANIXX Studio**. Play: **https://play.heyyanixx.de5.net/**

Tap to drop passengers (uncle, aunty with her sabzi bag, a goat, a gas cylinder, the dulha, the dhol wala…)
onto the roof of a moving auto rickshaw. Khadda (pothole) aaya toh tower hilega. 3 gire = **OVERLOAD!**

- Portrait 9:16, one thumb, ~30-second runs, best score saved on the device
- Mute + pause buttons, auto-pause when the tab is hidden
- No ads, no in-app purchases, no tracking, no cookies
- Pure HTML5 canvas + matter.js physics (MIT) + ZzFX sound synth (MIT) — see CREDITS.md
- `yt/` = YouTube Playables build (official SDK script tag + adapter in `yt.js`)
